# Semi-automatic Versioning Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** One source of truth (package.json) for the app version, bumped with `npm version`, auto-synced to Android + the in-app display, tagged in git.

**Architecture:** `package.json` `version` is the source. `npm version` bumps it and creates a git commit + annotated tag. An npm `version` lifecycle script runs `scripts/sync-version.js`, which rewrites `android/app/build.gradle` (versionName + versionCode) and regenerates `src/version.ts`; the Settings screen displays that constant. No new dependency.

**Tech Stack:** Node (plain CommonJS script), React Native / TypeScript, npm `version` lifecycle, git tags.

## Global Constraints

- No new dependencies (no `react-native-device-info`); display reads the synced `src/version.ts` constant.
- `package.json` `version` is the single source of truth; Android + in-app display are derived from it.
- Android `versionCode` must increase by exactly 1 on each bump (monotonic integer).
- `scripts/sync-version.js` is plain CommonJS (`.js`) — not type-checked by tsc (`tsconfig.json` includes only `**/*.ts`/`**/*.tsx`). Its self-check runs via `node scripts/sync-version.js --selftest` (node `assert`), NOT Jest.
- `src/version.ts` is a generated-but-committed file (the import target must exist on a fresh checkout).
- Verify with `npm run check` (lint + tsc + jest) where it applies.
- Per-task commits only; the user reviews/pushes.

### Task 1: Version-sync script with self-check

**Files:**
- Create: `scripts/sync-version.js`

**Interfaces:**
- Produces (internal to the script): `bumpGradle(text, version): string` — returns the gradle text with `versionName "<version>"` and `versionCode` incremented by 1.
- CLI: `node scripts/sync-version.js` runs the real sync (reads package.json, writes gradle + `src/version.ts`); `node scripts/sync-version.js --selftest` runs the assert-based check.

- [ ] **Step 1: Write the script with a failing self-check**

Create `scripts/sync-version.js` with a STUB `bumpGradle` (returns input unchanged) so the self-check fails first:

```js
const fs = require('fs');
const path = require('path');

const ROOT = path.resolve(__dirname, '..');
const GRADLE = path.join(ROOT, 'android/app/build.gradle');
const VERSION_TS = path.join(ROOT, 'src/version.ts');

// STUB — replaced in Step 3.
function bumpGradle(text, _version) {
  return text;
}

function syncGradle(version) {
  const text = fs.readFileSync(GRADLE, 'utf8');
  fs.writeFileSync(GRADLE, bumpGradle(text, version));
}

function writeVersionTs(version) {
  fs.writeFileSync(
    VERSION_TS,
    `// Generated by scripts/sync-version.js on \`npm version\`. Do not edit by hand.\nexport const APP_VERSION = '${version}';\n`,
  );
}

function main() {
  const version = require(path.join(ROOT, 'package.json')).version;
  syncGradle(version);
  writeVersionTs(version);
  console.log(`synced version ${version} → build.gradle + src/version.ts`);
}

function selftest() {
  const assert = require('assert');
  const out = bumpGradle('        versionCode 3\n        versionName "0.3.83"', '0.4.0');
  assert.ok(out.includes('versionName "0.4.0"'), 'versionName updated');
  assert.ok(out.includes('versionCode 4'), 'versionCode incremented by 1');
  const out2 = bumpGradle('        versionCode 9\n        versionName "1.2.3"', '1.2.4');
  assert.ok(out2.includes('versionCode 10'), 'versionCode 9 → 10');
  console.log('sync-version selftest passed');
}

if (require.main === module) {
  if (process.argv.includes('--selftest')) {
    selftest();
  } else {
    main();
  }
}
```

- [ ] **Step 2: Run the self-check to verify it fails**

Run: `node scripts/sync-version.js --selftest`
Expected: throws `AssertionError: versionName updated` (stub returns text unchanged).

- [ ] **Step 3: Implement `bumpGradle`**

Replace the stub with:

```js
function bumpGradle(text, version) {
  return text
    .replace(/versionName\s+"[^"]*"/, `versionName "${version}"`)
    .replace(/versionCode\s+(\d+)/, (_, n) => `versionCode ${Number(n) + 1}`);
}
```

- [ ] **Step 4: Run the self-check to verify it passes**

Run: `node scripts/sync-version.js --selftest`
Expected: prints `sync-version selftest passed`, exit 0.

- [ ] **Step 5: Commit**

```bash
git add scripts/sync-version.js
git commit -m "feat(version): sync-version script (gradle + version.ts) with self-check"
```
